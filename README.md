# 棚卸アプリ

棚卸リスト(xlsm/xlsx)の「現物」列を、スマホでQR・バーコードを読みながら埋めていくWebアプリです。GitHub Pages(静的サイト)でそのまま動きます。

## 公開手順
1. GitHubで新しいリポジトリを作成し、このフォルダの中身をすべてアップロード(`.nojekyll` を含める)
2. Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 表示されたURLをスマホで開く(HTTPSなのでカメラ・位置情報が使えます)。ホーム画面に追加するとアプリ風に使えます

## 使い方
1. 設定・出力 →「リストを読み込む」で棚卸リストを選ぶ(「最新データ」シート。ブラウザ内にだけ保存され、リポジトリには含まれません)
2. スキャン画面でQR・バーコードを枠に合わせると、自動で 現物=有 / 写真 / 位置情報を記録し、カメラは動いたまま次を読めます
3. 読めない時は自動でOCR(約5秒で試行)、または「文字を読む」ボタン。それでもだめなら「手入力」
4. 「写真を追加」で追加撮影(資産コード_001.jpg …)。「無」「確認中」は現物ボタンで切替
5. 一覧画面で検索・絞込・並べ替え。行をタップで詳細・写真・手修正
6. 設定・出力 → Excel(変更セルは黄色)/写真ZIP/記録CSV を出力

## 写真名
- 読取時: `資産コード_機番.jpg`(例 BARD7999_機番.jpg。「機番」は固定の文字)
- 追加: `資産コード_001.jpg`, `資産コード_002.jpg` …

## 注意
- データは端末のブラウザ内(IndexedDB)に保存されます。端末をまたぐ共有はありません。こまめに出力してください
- GitHub Pagesは公開サイトです。棚卸リストは含めず、各端末で読み込んでください
